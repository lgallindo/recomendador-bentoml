# Classwork — demanda da oficina (kits)

Série **sintética** só para o classwork de média móvel. É outro universo que a
série da aula (`dados/vendas_semanais.csv` + catálogo da loja).

| Arquivo | Conteúdo |
| --- | --- |
| [`demanda_semanal_oficina.csv`](demanda_semanal_oficina.csv) | 18 semanas × 6 kits (`k01`…`k06`) |

Colunas: `week_start`, `kit_id`, `order_line_count`.

| kit_id | Nome (rótulo de sala) |
| --- | --- |
| k01 | Kit cerâmica iniciante |
| k02 | Kit renda mesa |
| k03 | Kit xilo cartões |
| k04 | Kit palha cesto |
| k05 | Kit barro mini |
| k06 | Kit misto feira |

Use este CSV nas tarefas do Google Classroom. Não misture com os `p01`…`p12`
da aula.
